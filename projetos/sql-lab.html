O problema e a solução

Praticar SQL costuma exigir preparar um banco de dados e um ambiente de desenvolvimento. O SQL Lab oferece uma base fictícia já disponível e um editor integrado, permitindo que o estudante concentre a atenção na construção e na interpretação das consultas.

O mecanismo SQLite é carregado por CDN; a primeira inicialização depende de conexão com a internet.

Como funciona

01 · Escolher

Desafio progressivo

O usuário escolhe o nível e lê o enunciado, as colunas esperadas e a estrutura das tabelas.

02 · Executar

Consulta SQL real

O código é executado em um banco SQLite inicializado no próprio navegador, com resultados em tabela.

03 · Validar

Feedback imediato

O resultado é comparado à resposta de referência. Linhas em ordem diferente são aceitas quando os dados correspondem.

O aplicativo oferece dicas, soluções, estrutura das tabelas, indicador de progresso por nível, rascunhos salvos localmente e atalho Ctrl+Enter para executar consultas.

Decisões técnicas e limitações

As consultas são verificadas comparando suas colunas e linhas com o resultado de referência na base fictícia. Isso permite soluções SQL diferentes com a mesma saída, mas não comprova equivalência para qualquer conjunto de dados.

A aplicação restringe comandos de alteração para manter o foco didático. Essa filtragem textual não deve ser considerada uma barreira de segurança para execução de SQL não confiável em um servidor. O progresso é salvo apenas no navegador e não é sincronizado entre dispositivos.
